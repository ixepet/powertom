# PowerTom 模板制作规范(设计师版)

> 适用版本:powertom 0.1.x · 2026-11 · 配套工具:`rake powertom:check`
>
> 一句话:你在 PowerPoint 里做一份**普通的 pptx**——正文里写 `{{标签}}`,备注里写页级指令;工程师交数据,引擎产出成品 deck。排版、字体、配色、母版全部由你掌控,代码不碰设计。

---

## 30 秒上手

1. 做一页正常的幻灯片,把将来要被数据替换的文字写成 `{{字段名}}`:

   ```text
   欢迎使用 {{product_name}}
   本季度领养率 {{kpis[0].value}}
   ```

2. 如果这一页要"按数据复制多份",打开**备注**,写一行指令:

   ```text
   {{#each scenarios}}
   ```

3. 交付前跑一遍校验:

   ```bash
   rake powertom:check TEMPLATE=模板.pptx DATA=样例数据.toml
   ```

   `error` 必须修,`warning` 建议看一眼。都能过,渲染出的 deck 就能在 PowerPoint 里正常打开。

## 1. 标签:正文里的 {{ }}

### 1.1 语法

| 写法 | 含义 | 示例数据 |
| --- | --- | --- |
| `{{字段}}` | 顶层字段 | `title: "年度总结"` → `{{title}}` |
| `{{数组[编号].字段}}` | 数组里第几项的字段 | `kpis[0].name` → "领养率" |
| `{{a.b.c}}` | 逐层往下取 | `school.name` |
| `{{字段:formatter}}` | 数字/日期格式化(见 1.3) | `price:currency` → "¥1,234.56" |

- 一个段落里可以有多个标签:`{{first}} 与 {{second}} 双标签` 是合法的。
- 标签前后可以留空格:`{{ title }}` 与 `{{title}}` 等价。
- 标签可以放在**任何文本框**里,包括组合形状里面的(引擎会进到组合里找)。

### 1.2 样式从哪来(重要)

**标签写在哪个 run,替换后就继承哪个 run 的样式。占位标签什么样,成品就什么样。**

两条实操建议:

- 选中 `{{title}}` 整体,一次性设置字号/颜色/加粗。不要"半截字设成红色半截设成黑色"。
- **不要在一个段落里混用多种样式再放标签。** PowerPoint 会把一行字拆成多个 run(输入法、拼写检查、反复编辑都会触发),引擎会把整段替换后的文字并入第一个 run——也就是说,**带标签的段落,成品样式以段落里第一个字的样式为准**,后面 run 的样式会被清空(保留占位,不破坏文件)。想让一段里有两个不同样式的部分,拆成两个段落,各自放标签。

### 1.3 formatter:数字与日期的格式化

| 标签 | 数据值 | 成品 |
| --- | --- | --- |
| `{{price:currency}}` | 1234567.891 | ¥1,234,567.89 |
| `{{price:currency.0}}` | 1234.6 | ¥1,235 |
| `{{ratio:percent.1}}` | 0.297 | 29.7% |
| `{{count:number}}` | 12345 | 12,345 |
| `{{day:date}}` | 2026-11-16 | 2026-11-16 |
| `{{day:date.year_month}}` | 2026-11-16 | 2026年11月 |
| `{{day:date.cn}}` | 2026-11-16 | 2026年11月16日 |

- 冒号后是 formatter 名,`.参数` 控制小数位或子格式。
- currency / percent / number 要求数字,date 要求日期;类型不对,渲染会报错。
- 需要新格式,让工程师注册自定义 formatter——标签不用改。
- formatter 名写错,`powertom:check` 会报 error 并列出可用名。

### 1.4 什么能放,什么不能放

| 可以 | 不可以(v0 会报 error) |
| --- | --- |
| `{{title}}`、`{{kpis[0].value}}`、`{{a.b.c}}` | 表达式、运算、方法调用 |
| 一个段落多个标签 | `{{#each x}}` 写在**正文**(指令只能进备注) |
| 组合形状内的标签 | 路径里有空格、连字符、中文 |
| formatter:`{{price:currency}}` | 不存在的 formatter 名(check 会列出可用名) |

表格单元格可以写标签;如果整行要按数组展开,见 §2.4 表格行循环。

图表数据 **v0 不绑定**——图表里的 `{{x}}` 会原样保留。需要图表时,让工程侧出图片,用图片占位贴进去(见 §4)。

### 1.5 数据没有这个字段会怎样

- 校验阶段:`powertom:check` 直接报 error,告诉你"第几页、哪个文本框、缺哪个字段"。
- 渲染阶段:默认(strict)抛错终止;工程师传 `strict: false` 时该处填空白并在终端记 warning。
- 所以字段名写错不会"静默出空白 deck",放心改。

## 2. 页级指令:写在备注里

指令只写在**幻灯片备注**里,放映时看不见,不污染画面。**一页备注只允许一条指令**,写两条校验会报错。

### 2.1 `{{#each 数组}}`:一页模板,数据出多页

备注写:

```text
{{#each scenarios}}
```

正文里直接写每一项的字段:

```text
{{headline}}
{{detail}}
```

数据里 `scenarios` 有 3 项,这一页就会被克隆成 3 页,分别取每一项的值;后面的页面自动顺延。

- **数组为空(0 项)时,这组页面整组删除。** 设计模板时要想清楚:某组页全被删掉后,deck 剩下的结构还成不成立(比如目录页的编号是否还对)。
- 循环路径在数据里缺失或不是数组,渲染会直接报错——不会静默丢页。

### 2.2 `{{#if 字段}}`:为假删整页

```text
{{#if show_compare}}
```

- 字段为 `false` 或空(nil)→ 这一页删除;其他值 → 保留。
- `#if` 页里的普通标签照常绑定(不改变作用域)。
- 校验时如果样例数据里该字段为假,check 会提示"渲染时该页将被删除"——这是提醒不是错误。

### 2.3 备注的其他用法

- 备注里的**普通文字**(设计说明、交接话术)随便写,引擎不渲染备注,会原样保留。
- 唯一注意:别把设计说明写成 `{{xxx}}` 的形态,校验会警告"备注含标签,v0 不渲染备注"——看到这条警告说明你手滑了。
- 用 WPS 做模板的同事:WPS 会在备注里留下它的元数据,引擎会自动忽略,不用清理;但写 `{{#each}}` 指令前,建议把旧备注清掉再写,避免混淆。

### 2.4 表格行循环:{{数组[].字段}}

表格里的一行,只要单元格里出现 `{{数组[].字段}}`,这一行就是**模板行**,渲染时按数组条数克隆:

| 班级 | 均分 |
| --- | --- |
| `{{classes[].name}}` | `{{classes[].avg}}` |
| 年级合计 | `{{total_avg}}` |

- 表头行、合计行照常保留;只有带 `[]` 的那一行会被替换成多行。
- 同一行里的 `[]` 标签必须指向同一个数组;一张表只允许一个循环行。
- 数组为空(0 项)时,**这一行整行删除**,表头与合计仍在。
- 循环行里不带 `[]` 的标签(如合计)仍然从整页数据取,不受行数据影响。
- `[]` 只能写在**表格单元格**里;写在正文文本框或备注里会直接报错。
- 同一页上不能同时用页级 `#each` 和表格行循环(只支持一层循环)。

表格单元格也支持 formatter,例如 `{{classes[].avg:number.1}}`。

> 校验:`powertom:check` 会对数组逐项对账,缺字段会告诉你"第几项、期望的路径";空数组会提示"循环行会被移除"。
>
> 两级嵌套见 §2.5;动态列(`#grid`)仍属于规划中的进阶语法,设计见[表格循环语法设计](表格循环语法设计.md)。

### 2.5 表格嵌套行:{{#rows 路径}}

"班级 → 学生"这类两级结构,用**标记行 + 内容行**成对声明:

| 班级 | 学生 | 总分 |
| --- | --- | --- |
| `{{#rows groups}}` |  |  |
| `{{groups[].name}}` | `{{groups[].avg}}` |  |
| `{{#rows groups[].items}}` |  |  |
| `{{groups[].name}}` | `{{groups[].items[].name}}` | `{{groups[].items[].total}}` |
| 年级合计 |  | `{{total_count}}` |

- `{{#rows 父数组}}` 与 `{{#rows 父数组[].子数组}}` 必须**独占首列单元格**,该行其余单元格留空;标记行本身不输出。
- 标记行的**下一行**就是它的内容行;固定顺序:父标记 → 父内容 → 子标记 → 子内容。
- 标签一律写**完整路径**:父行 `{{groups[].字段}}`,子行 `{{groups[].items[].字段}}`;子行也可以引用父级字段。
- 只支持**两级**;第三个 `#rows` 标记会报错。同一张表不能与 `[]` 行循环混用。
- 空数组:父数组为空 → 父子行全部删除;某个父项的子数组为空 → 只保留该父内容行。
- 循环区域(标记行与内容行)不允许合并单元格;需要合并请先拆表。

> 数据形状:`groups` 是数组,每一项里再放一个 `items` 数组。`powertom:check` 会逐级对账,报错指出"父级第几项、子级第几项、期望的完整路径"。

### 2.6 表格动态列:{{#grid rows: 数组 cols: 数组 [value: 字段]}}

分数段、指标列随考试配置变化时,用**动态列**。模板固定两列:首列行标题,第二列是列模板。

| 班级 | 分数段 |
| --- | --- |
| `{{#grid rows: distribution cols: bands value: counts}}` | `{{col.label}}` |
| `{{row.name}}` | `{{cell}}` |

- 标记写在**表头行首列**,同格可以保留文字(如「班级 {{#grid ...}}」);标记本身不会出现在成品里。
- 紧随其后的一行是**内容行模板**;表格其余行按普通行处理。
- 第二列表头用 `{{col.label}}`(或 `{{col.字段}}`;列项是标量时用 `{{col}}`)。
- 内容行:首列写 `{{row.字段}}`,数据列写 `{{cell}}`(行列交叉值)。
- 数据形状:`distribution` 是行数组,`bands` 是列数组;有 `value: counts` 时取 `row.counts[col.key]`,省略时取 `row[col.key]`。
- 列项是 Hash 时必须有 `key` 字段,它是该列的取值键。
- 表格必须是**两列**模板;生成的列沿用第二列的列宽。
- 空 `cols` → 只保留首列;空 `rows` → 只保留表头。
- `#grid` 不能与 `#rows` 或 `[]` 混用,也不支持合并单元格;不能与页级 `#each` 叠加。

> `powertom:check` 会逐行/逐列/逐交叉值对账:报错会指出"数组第几项"或"第几行 × 第几列"。

## 3. 占位文本与文字溢出

**autofit 关闭时,文字溢出文本框不会被裁掉,而是直接溢出画面。** 标签本身只有几个字,数据进来后动辄几十字,这是模板最常见的翻车点。

规则与建议:

- 引擎的预警线:**绑定后 ≥20 个字,且超过标签长度 2 倍** → `powertom:check` 出 warning。
- 给标签所在文本框**预留至少 2 倍于标签长度的版面**,或者:
  - 打开"缩小文字以适应形状"(autofit shrink);
  - 或让字段值短一些(和工程师约定数据长度)。
- 多行文案同理:`{{intro}}` 一行放不下,给文本框留出多行高度。

## 4. 图片占位

图片替换按形状名称或 alt text(替换文字)定位,约定:

```text
形状名称 = powertom:image:字段名
```

例如封面主视觉命名 `powertom:image:cover`,团队风采页命名 `powertom:image:team_photo`。数据里对应字段的值 = **图片文件路径**(建议绝对路径),PNG / JPEG 都可以。

- 替换策略固定为"**填满形状、居中裁切**":占位图摆什么比例,成品就按什么比例裁,所以**占位图请直接用目标比例**(16:9 的版面就放 16:9 的占位图)。
- `#each` 克隆页同样支持:占位图放在循环页上,数据每一项里各自给路径,克隆出的每页换上各自的图。
- 图片字段缺失(非 strict 模式)时保留占位图并记 warning;字段给了但**文件不存在**会直接报错。
- `powertom:check` 会检查图片字段:缺失、类型不对、文件不存在都报 error——交付模板前跑一遍最稳。

## 5. 母版、版式与封面

- **标签不要写在母版或版式上。** 引擎只处理页面上的形状,母版里的 `{{x}}` 不会被替换,也不会报错——它会原样出现在每一页上。
- 版式(layout)建议收敛:一个模板里 3–5 个版式足够(参考 HaiMate 模板:62 个版式里实际只用了 4 个)。版式越少,克隆页的还原度越稳。
- **封面注意**:如果封面标题是烙在整张背景图里的(图片里画着字),引擎绑不了它。要做可替换的封面标题,请放一个真文本框写 `{{cover_title}}`。
- 同一页上同名形状(比如两个都叫"文本框 8")是允许的,错误信息里会用"文本框 8#2"区分;但建议给关键文本框起有意义的名字(如"痛点-标题"),报错时一眼定位。

## 6. 交付前自查

```bash
# 带样例数据:字段对账 + 溢出预警 + 语法与结构检查
rake powertom:check TEMPLATE=模板.pptx DATA=样例数据.toml

# 没有样例数据:只查语法与结构
rake powertom:check TEMPLATE=模板.pptx
```

- `error`:不修掉就渲染不了(缺字段、指令语法错)。
- `warning`:不阻断,但每一条都值得看——它们几乎都是"成品 deck 上会难看"的预兆。
- 工程师那边的报错长这样:`第 2 页 形状'圆角矩形 4':{{workload}} 数据里没有字段 'workload'`——按这个格式自己在模板里找位置即可。

数据文件格式是 TOML(工程师侧维护),样式参考:

```toml
title = "2026 年度总结"
show_outlook = true

[[scenarios]]
headline = "晨读材料包自动生成"
detail = "每周日晚 8 点"
```

## 7. 常见坑速查

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| 成品某段样式变了 | 段落混用样式 + 标签,替换后并入首个 run | 标签所在段落不要混样式 |
| 文字溢出画面 | 数据比标签长,autofit 关闭 | 见 §3,留 2 倍版面或开缩字 |
| 标签原样出现在成品 | 标签写在母版/版式上,或在表格/图表里 | 移到页面文本框 |
| `powertom:check` 报"只允许一条指令" | 备注里写了两个 `{{#...}}` | 一页一条,另一页另写 |
| 循环页渲染报错"无法确定循环次数" | 数据里没有 #each 指定的数组 | 和工程师对字段名 |
| 报错里形状名带 `#2` | 页面上有同名形状 | 建议重命名,便于定位 |
| 标签被拆成碎块仍能替换 | 引擎已做段落级合并,无需处理 | 保持一次性输入标签的习惯即可 |
