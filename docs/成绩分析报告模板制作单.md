## 1. 全局约定

| 项 | 约定 |
| --- | --- |
| 画布 | 16:9(13.33 × 7.5 in) |
| 字体 | 思源黑体(Source Han Sans CN);正文 ≥ 14pt,指标数值 ≥ 32pt |
| 形状命名 | 带标签的文本框按本单命名(如 `封面-标题`);图片按 `powertom:image:<字段>` 命名 |
| 备注 | **只有 P4、P7 写指令**;其余页面备注留空,不要出现任何 `{{...}}` |
| 样式 | 带标签的段落只用一种字号/颜色,不混排(否则替换后以第一个 run 为准) |
| 表格 | 本版不做表格;用指标卡 / 条目文本 / 图表图片表达 |
| 版式 | 封面 / 内容 / 循环页 / 结束 四种足够,不新造版式 |

### 1.1 工程已提供的起点

`examples/score_report/template_scaffold.pptx` 是按本单生成的 **7 页结构脚手架**:

- 形状名、标签、备注指令、图片占位都已按本单做好,`powertom:lint` 当前 0 error;
- 字体用 `PingFang SC` 占位,图片用灰色占位图,**没有任何视觉设计**;
- 设计师可直接在它上面做视觉:改颜色、字体、字号、位置、背景,不要改形状名与标签;
- 改了也安全:`powertom:lint` 会把"缺少形状 / 缺少标签 / 契约外标签"指出来。

重新生成脚手架(覆盖前请先另存设计师版本):

```bash
ruby tools/build_score_report_template.rb
```

## 2. 逐页规格

> 「占位文本」直接抄进文本框;「形状名」在 PowerPoint 的「选择窗格」里改。
> 建议长度按溢出预警线给出(绑定值 ≥20 字且 ≥ 标签长度 2 倍会告警),按建议写不会误报。

| 形状名 | 类型 | 占位文本 | 字号 | 建议长度 |
| --- | --- | --- | --- | --- |
| 封面-标题 | 文本框 | `{{report_title}}` | 40 加粗 | ≤ 28 字,最多 2 行 |

## 5. 禁止事项

| 禁止 | 原因 |
| --- | --- |
| 在母版 / 版式上写标签 | 引擎只处理页面形状,母版上的标签会原样出现在每一页 |
| 一页备注写两条指令 | 校验直接报 error |
| 在表格 / 图表里写标签 | v0.1 不绑定,标签会原样保留 |
| 在带标签的段落里混排字号/颜色 | 替换后统一为第一个 run 的样式 |
| 把 `{{tips[3].text}}` 写成 4 条 | 下标必须与数据条数一致,缺项会报 error |
| 图片占位名拼错 | 不会报错,但也不会替换(静默失效),命名后自查一遍 |
| 用 WPS 保存后把旧备注留下 | 备注里的旧文字会被当作设计说明保留;写指令前先清空备注 |

**验收步骤(设计师自查,工程复核)**

```bash

  TEMPLATE=examples/score_report/template.pptx \
  CONTRACT=examples/score_report/template_contract.toml \
  DATA=examples/score_report/sample.toml

  TEMPLATE=examples/score_report/template.pptx \
  DATA=examples/score_report/sample.toml
```
